# Bot ETF Seguimiento — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replicar el bot de seguimiento de ETFs de la web de un amigo, con la misma estrategia (media de 10 meses), los mismos 4 ETFs en Xetra, capital inicial de 1.000 €, y publicarlo en GitHub Pages con actualización diaria automática.

**Architecture:** Un script Python (`generar.py`) descarga precios mensuales de Yahoo Finance, calcula el backtest histórico y el estado actual del trial, genera un JSON `DATOS` y lo inyecta en `plantilla.html` para producir `index.html`. GitHub Actions ejecuta el script cada día y GitHub Pages publica el resultado.

**Tech Stack:** Python 3.11+, yfinance, pandas, GitHub Actions, GitHub Pages

**Spec:** Conversación del 2026-10-26 — réplica fiel de seguimiento-etf.pages.dev

## Global Constraints

- ETFs Xetra: EUNL.DE, IS3N.DE, XGLE.DE, 4GLD.DE (Yahoo Finance)
- Estrategia: SMA de 10 cierres mensuales; buy/hold si precio > SMA, vende si precio ≤ SMA
- Capital inicial: 1.000 €; comisión por orden: 2 €; solo acciones enteras
- Backtest histórico desde 2005; prueba "en seco" últimos 12 meses
- Trial actual: inicio_medicion 2026-11-01, fin_prueba 2027-01-31, umbral −2,48 %
- Estado persistente del trial en `estado.json` (posiciones actuales + órdenes)
- Datos en JSON embebido en el HTML (`const DATOS = ...`)
- Un solo HTML estático (`index.html`) sin servidor ni dependencias externas en el cliente

## Review Focus

- **Datos insuficientes en Yahoo Finance**: algunos ETFs pueden no tener historia desde 2005; rellenar con NaN y excluir del backtest hasta que empiecen a cotizar.
- **Fin de mes en día no hábil**: siempre usar el último día de cotización del mes, no el día 30/31 literal.
- **Zona horaria**: Xetra cierra a las 17:30 CET; los precios de cierre en Yahoo son en la zona local del mercado. Usar precios `Close` sin ajuste de zona.
- **Comisión mínima de IB**: 1,25 € + tasas ≈ 2 €; aplicar solo cuando hay compra o venta real (cambio de posición).
- **Rebalanceo mensual**: solo al final del mes se toma la decisión; durante el mes se muestra la señal provisional ("si el mes cerrara hoy").
